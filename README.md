\# SQL Case Study 1



\## Project Overview



This project is a SQL Server case study focused on analyzing business data related to sales, profit, products, expenses, inventory, marketing, and geographical markets.



The objective of this case study is to apply SQL concepts to answer a few questions about your customers, especially about the sales and profit coming from different states, money spent in marketing and various other factor such as COGS(Cost of Good Sold), budget profit etc.



The project uses SQL Server and demonstrates both fundamental and advanced SQL querying techniques.



\## Objectives



The main objectives of this case study are to:



\* Analyze sales and profit data.

\* Calculate business metrics using aggregate functions.

\* Filter and sort business records.

\* Combine information from multiple tables using JOINs.

\* Perform state-wise and product-wise analysis.

\* Use subqueries to solve business problems.

\* Apply window functions for ranking.

\* Create and execute stored procedures.

\* Create and use a user-defined function.

\* Work with transactions and rollback.

\* Use set operators such as UNION and INTERSECT.

\* Perform conditional analysis using `IIF`.

\* Generate hierarchical results using `ROLLUP`.

\## Dataset



The project contains three tables:



\### 1. Fact



The `Fact` table contains transactional/business information such as:



\* Date

\* Product ID

\* Profit

\* Sales

\* Margin

\* COGS

\* Total Expenses

\* Marketing

\* Inventory

\* Budget Profit

\* Budget COGS

\* Budget Margin

\* Budget Sales

\* Area Code



\### 2. Location



The `Location` table contains geographical and market information:



\* Area Code

\* State

\* Market

\* Market Size



\### 3. Product



The `Product` table contains product information:



\* Product ID

\* Product Type

\* Product

\* Type



\---



\## Table Relationships



The tables are connected using the following keys:



Fact.ProductId  -  Product.ProductId



Fact.Area\_Code  -  Location.Area\_Code





This allows sales, profit, product, and geographical information to be analyzed together.

\## Business Questions



The case study contains 29 SQL questions/tasks covering areas such as:



1\. Number of states present in the Location table.

2\. Number of regular-type products.

3\. Total marketing expenditure for Product ID 1.

4\. Minimum product sales.

5\. Maximum COGS.

6\. Details of coffee products.

7\. Records where total expenses exceed 40.

8\. Average sales for Area Code 719.

9\. Total profit generated by Colorado.

10\. Average inventory for each product.

11\. States in sequential order.

12\. Total sales on a specific date.( Skipped due to wrong question)

13\. Average total expenses by product and date.

14\. Combining Fact, Location, and Product information.

15\. Ranking sales using `DENSE\_RANK()`.

16\. State-wise sales and profit.

17\. State-wise sales and profit by product.

18\. Calculating sales after a 5% increase.

19\. Finding maximum profit with product information.

20\. Creating a stored procedure based on product type.

21\. Categorizing records as Profit or Loss based on expenses.

22\. Generating weekly sales using `ROLLUP`.

23\. Applying `UNION` and `INTERSECT`.

24\. Creating a user-defined function.

25\. Updating data using a transaction and undoing it with `ROLLBACK`.

26\. Filtering expenses between 100 and 200.

27\. Deleting regular-type products.

28\. Extracting an ASCII value from product data.
